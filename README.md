
# AI-Powered Fragrance Recommendation Store

An AI-powered fragrance store that helps users discover perfumes based on their preferences, budget, occasion, and desired scent profile.

## Planned Features

- Natural-language fragrance search
- Semantic search using text embeddings
- Personalized perfume recommendations
- Budget-aware product filtering
- Explanations for recommended products
- Product catalog and database
- Full-stack web interface

## Technology Stack

- Python
- FastAPI
- SQLite
- Sentence Transformers
- React
- Git and GitHub

## Project Status

Currently setting up the project foundation.

## Goal

Build a zero-cost, full-stack AI recommendation application
with measurable recommendation quality and automated tests.
